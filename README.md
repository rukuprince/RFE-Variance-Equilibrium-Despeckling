# RFE-Variance-Equilibrium-Despeckling

This repository accompanies the manuscript “Deterministic Locality Algorithm for Structure-Preserving Speckle
Suppression via Radial Flux Equilibrium”, which proposes a deterministic, variance–equilibrium framework for speckle suppression in coherent imaging
modalities.

The method formulates despeckling as a solved statistical equilibrium problem governed by

Radial Flux Equilibrium (RFE), combining:
- Fisher-motivated automatic ROI selection,
- a closed-form variance identity that analytically determines frequency-domain gains, and
- a moment-only locality interface that enables kernel-agnostic ENL control with
  radiometric fidelity.

## Code Availability

The full implementation is available upon reasonable request for academic research and
peer-review purposes. This public repository provides methodological documentation,
dataset provenance, and access instructions.
